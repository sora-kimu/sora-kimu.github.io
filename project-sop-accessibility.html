SOP Retrieval — Access as Upstream Condition

Procedural archives that block keyword search become an obstacle before any task begins. This project treats SOP accessibility not as a usability detail but as the foundation of authorized action — a structural condition shaping which procedures practitioners can apply, compare, and defend against.

📋 Pilot study 👥 N=20 GMP practitioners 📚 500-SOP synthetic corpus 🛠 Streamlit + Python
📖 Background
What is an SOP?
Standard Operating Procedure — formal, step-by-step procedural documents that govern action in regulated work. In GMP (Good Manufacturing Practice) environments such as pharmaceutical manufacturing, every action must follow an approved SOP; non-compliance triggers FDA Warning Letters or facility shutdown. SOPs are typically stored as scanned PDFs in legacy archives, organized by folder hierarchy that requires tacit knowledge to navigate.

01 The problem — access blocks judgment
▼

Procedural archives stored as scanned PDFs force reliance on folder memory — a structural mismatch between how documents are organized and how people actually search.

Observed friction in regulated archives:

  • Scanned files block keyword search entirely
  • Similar or generic titles create ambiguity
  • Users open multiple wrong files before locating the target
  • Access requires archive-naming familiarity (tacit knowledge)
  • Time pressure amplifies every friction point

What later looks like individual difficulty — "the operator couldn't find the SOP" — often begins as structural difficulty upstream. This is the point where accountability conditions start quietly forming, before anyone acts, before anyone is assigned responsibility.

02 The design — external layer, no automation
▼

A keyword-searchable metadata layer operating over validated archives — never modifying source files.

▸ Search interface · demo
Keyword entry replaces filename memory — users enter task terms, not document titles.
Constraint
Validated SOP files cannot be modified — any change requires full revalidation under GMP regulations.
Decision
External retrieval layer. Search operates over a metadata index, not source files. Keyword-based access decouples retrieval from archive structure while preserving document integrity.
Trade-off
No automation of interpretation or compliance decisions. The system surfaces documents; practitioners retain full responsibility for reading, applying, and judging.
03 AI support layer — interpretive scaffold
▼

A conceptual extension that expands the set of retrievable and comparable procedural cues — making ambiguity more visible without replacing interpretation.

Conceptual extension only. No separate pilot study was conducted; this is included as a design direction rather than an empirical claim.
▸ AI layer · demo
Explains why a result appeared, surfaces related procedures, keeps interpretive options open.

Retrieval is only one component of procedural usability. Interpretive support may be necessary when the goal is to preserve reasoning openness in regulated environments.

04 Pilot study — N=20 think-aloud
▼

Participants initially relied on folder memory and trial-and-error file opening. With the retrieval layer, they shifted to direct keyword-based access. As retrieval effort decreased, attention reallocated toward document reading rather than navigation.

The strongest signal was not that all friction disappeared — it was that ambiguity became more visible and tractable, separating user difficulty from structural difficulty in the archive itself.

05 What this revealed
▼

Accessibility is upstream of judgment. When practitioners cannot find the right document, they fall back on what they remember — constraining their behavioral repertoire before any task begins. In regulated work, this is a direct constraint on authorized action, not just efficiency.

"When you cannot find a SOP easily, you end up acting within the SOPs you already know."

This reframes retrieval friction as a structural condition shaping accountability — a quiet upstream feature that determines what can later become visible, comparable, and defensible.

It also means Layer 1 has to work first. The remaining three layers (Structure, Coordination, Reasoning) all assume practitioners can locate the documents they need. Without Accessibility, judgment-preserving design at higher layers has no foundation.
